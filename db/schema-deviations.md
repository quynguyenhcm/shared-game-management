# Schema deviations from `database-design.md`

Every difference between the migrated schema (`db/migrations/*.sql`) and the draft in the repo-root
`database-design.md` is listed here with the requirement it comes from (AC-INTEGRATION-1).
`apps/api/test/integration/schema.int.test.ts` compares the live catalog with a hand-written copy of
the draft (`apps/api/test/fixtures/expected-schema.ts`) and fails if a difference is missing from the
**Objects** column below, or if a row has no **Source**.

Object keys: `table:<t>` new table · `column:<t>.<c>` new column · `type:<t>.<c>` changed type ·
`nullability:<t>.<c>` nullable → NOT NULL · `fk:<t>.<c>` changed foreign key (target or ON DELETE) ·
`enum:<e>` new enum type · `function:<f>` new SQL function. Other keys (`constraint:`, `index:`,
`trigger:`, `extension:`) are documentary; the test does not derive them.

Source abbreviations: **Task gap** = task description gap list (`memory-bank/tasks/platform-foundation.md`
→ Task Description); **AC-…** = acceptance criterion in the same file; **Arch Qn** / **Algo Qn** =
`memory-bank/creative/platform-foundation-architecture.md` / `-algorithm.md` decision; **Critique n** =
Codex design critique finding n (disposition 2026-09-29); **productBrief** = `memory-bank/productBrief.md`
NFR; **Workflows §n** = `workflows_state_machine_architecture.md`; **P1–P7** = Architectural Principles.
